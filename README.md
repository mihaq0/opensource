# NightRun

Windows 10/11 x64; сборка требует .NET 8 SDK. Для запуска драйвера нужны права администратора.

## Сборка

```powershell
dotnet publish NightRun.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
dotnet publish loader/NightRun.Loader.csproj -c Release -o publish
```

Скопируйте в `publish` из `runtime` файлы `load-driver.ps1`, `start-overlay.ps1`, `zxmapper.exe` и `kernel-mode.sys`. Запустите `NightRun.Loader.exe`: сначала загрузите драйвер при закрытой игре, затем запустите игру и оверлей. Скрипты откроются в отдельных окнах и при необходимости запросят повышение прав. Настройки доступны отдельно.

Загрузчик является self-contained single-file приложением, но **не содержит** оверлей, драйвер, mapper или скрипты: их необходимо разместить рядом. См. `runtime/README.txt` для управления и деталей запуска.

При включённом Loot строка состояния (видна при открытом меню или включённом FPS) показывает количество найденных объектов, проверенных записей, ошибок чтения и доступных словарей. Нулевой результат не доказывает отсутствие предметов: адреса и структура данных зависят от версии игры.

## Диагностика наведения

Включите Aim, закройте меню (наведение при открытом меню отключено), держите выбранную клавишу и сфокусируйте окно игры. Внизу экрана и в `nightrun_diag.log` показывается состояние: `key`, `focus`, `camera stale`, `no target (filter/range)`, `no target (projection)`, `no target (fov ...)`, `lock ...` или `input rejected`. Лог обновляется примерно раз в пять секунд, поэтому удерживайте клавишу достаточно долго. При `lock` Windows может принять синтетический ввод, но игра всё равно может его игнорировать — успешный `SendInput` не гарантирует поворот камеры.
