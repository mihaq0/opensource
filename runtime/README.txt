NightRun — оверлей для ROB RUN
===============================

Требуется: Windows 10/11 x64, права администратора.
Устанавливать .NET не нужно — всё уже внутри архива.

Порядок запуска (важно!)
------------------------
1. Игра ROB RUN должна быть ЗАКРЫТА.
   Двойной клик по "1-driver.bat" → подтверди UAC → дождись "Driver loaded".
2. Запусти игру ROB RUN.
3. Двойной клик по "2-overlay.bat" → подтверди UAC → оверлей включится.

Драйвер грузится только при закрытой игре — поэтому два отдельных батника.

Управление
----------
  RShift  — открыть/закрыть меню
  F1 — рамки        F2 — aim          F3 — скелет
  F4 — мёртвые      F5 — хитбоксы     F6 — дистанция
  F7 — свой бокс    F8 — лут          F9 — выключить всё
  F10 — выход

Настройки сохраняются в nightrun.json рядом с NightRun.exe.
После смены сборки игры адреса находятся автоматически (1–2 минуты, статус RESOLVING).

Если антивирус удаляет zxmapper.exe или kernel-mode.sys — это загрузчик драйвера,
добавь папку в исключения.
